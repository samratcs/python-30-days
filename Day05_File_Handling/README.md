# Day 05 — File Handling in Python

## 📌 Overview

File handling in Python allows us to create, read, write, and modify files directly from a Python program.

In this day's exercises, we will mainly use the `with open()` statement because it automatically closes the file after the operation is completed.

---

## 🎯 Learning Objectives

By the end of Day 05, you will understand:

- How to open a file in Python
- How to read file contents
- How to write data to a file
- How to append data to an existing file
- How to read files line by line
- How to count lines, words, and characters
- How to work with log files
- How to use different file modes
- Why `with open()` is preferred for file handling
